# Native Tables for Obsidian

在 Obsidian 的实时预览中直接编辑 Markdown 表格。支持合并单元格、行列尺寸、文字与边框格式、排序和筛选，界面跟随 Obsidian 主题。

**当前版本：0.4.1 · 桌面端开发预览版**

## 安装

1. 从 [Releases](https://github.com/BusyStudyingWu/obsidian-native-tables/releases) 下载 `main.js`、`manifest.json`、`styles.css`，或下载完整安装包后解压。
2. 将三个文件放入你的 Obsidian 仓库：`.obsidian/plugins/native-tables/`。
3. 在「设置 → 第三方插件」中启用 **Native Tables**。
4. 打开含标准 Markdown 表格的笔记，切换到「实时预览」。也可通过命令面板运行「Native Tables: 插入增强表格」。

更新时覆盖三个安装文件，再关闭并重新启用插件。建议先在测试笔记中体验。

## 功能与操作

- **选择**：单击选格、拖动框选、Shift 扩展。选中后显示上方浮动工具栏与灰色行列选择条；选择条支持整行、整列选择。点击表格外或按 Esc 收起选中高亮和控件。
- **编辑**：双击、Enter 或直接输入开始编辑。Enter 保存，Shift+Enter 换行，Esc 取消，Tab/Shift+Tab 保存并移动。方向键移动，Shift+方向键扩展，Delete 清空。
- **合并/拆分**：支持跨行、跨列与表头合并。合并时按行拼接非空内容；未经编辑拆分恢复原文，编辑过的合并格拆分后保留当前左上角内容。
- **尺寸**：拖动任意单元格右边缘调列宽，下边缘调行高。悬停预览对应行列，松开保存。尺寸面板支持精确输入；只修改实际更改的尺寸字段。行高是最小高度，长内容仍可撑开。
- **格式**：字号、粗体、斜体、下划线、删除线、字体色、文字突出显示、底色、水平和垂直六种对齐。
- **边框**：单侧、内框、外框、全部、无框、内部横线/竖线、斜线。设置窗口支持实线、虚线、点线、双线、颜色、粗细和可点击预览，确认后应用。
- **行列**：按数量向上下左右插入，删除含内容的行列前确认。存在合并格时需先拆分再增删行列。
- **链接与批注**：为区域内容插入 Markdown 链接，添加保存在笔记内的单元格批注。批注通过单元格标记和提示显示，不连接外部评论服务。
- **排序与筛选**：右键或更多表格操作。首行不参与排序，非空值全部为数字时按数字排序，否则按文本排序，空值置底。筛选仅隐藏当前视图的行，不删除数据或保存条件。存在跨行合并时须先拆分。
- **复制粘贴**：支持 Excel HTML 和 TSV，范围不足自动扩展；与现有合并区域交叠时要求先拆分。支持编辑器撤销/重做内容和格式。
- **原生回退**：右键使用原生表格编辑，设置中可全局关闭增强编辑。

## 数据保存

可读内容保存在 Markdown 表格中，紧邻的 `<!-- native-tables:… -->` 注释保存版本、表格 ID、合并恢复信息、尺寸及样式。仅浏览和选中普通表格不会写入元数据。停用插件后，表格文字仍可阅读。

外部源码修改导致结构冲突、元数据损坏或版本不支持时，插件暂停增强编辑并保留文本，提供明确的重置格式入口。重置会丢弃旧格式与合并恢复信息。

## 范围与限制

- 仅增强桌面端的顶层标准 Markdown 表格；引用、列表内嵌及非标准语法保持原生。
- 不提供公式计算、多工作表、行列拖动重排或多人评论服务。
- Excel 导入识别 HTML 内联样式，不承诺完整 Office 格式往返。
- 同样接管实时预览表格的第三方插件可能冲突，可使用原生回退。
- 这是开发预览版；深色/第三方主题、分屏、多插件共存、大表格实际滚动等仍需进一步验证。

## 开发

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run check
npm test
node integration.mjs
npm run build
```

默认输出到 `dist/`。将 `dist/main.js`、`dist/manifest.json`、`dist/styles.css` 复制到插件目录即可。项目根目录也提供当前版本安装文件。

测试包括 Markdown 与元数据读写、中文与管道符、合并恢复、排序、行列变更，以及基于真实 CodeMirror、jsdom 和 Obsidian API 替身的交互集成验证。200×20 数据往返检查不等同于 Obsidian 实际滚动性能测试。
